# 展示素材与截图清单

架构图和 Agent 图已写在 README 的 Mermaid 代码块中，可直接由 GitHub 渲染；`docs/architecture.md` 另有任务时序图。以下截图仅在完成真实运行后添加，不要使用模拟结果冒充实测。截图前隐藏 Token、Cookie、API Key、密码、个人信息、绝对路径及无关数据。

| 建议文件名 | 应展示的真实内容 | 获取方法 |
| --- | --- | --- |
| `swagger.png` | 本项目 Swagger 中的主要接口 | 启动服务后访问 `http://127.0.0.1:8002/docs` 截图 |
| `postman-tests.png` | 测试服务中一次真实执行的断言结果 | 在 8003 测试服务登录，运行上传、任务查询和重复请求用例；保留实际成功与失败结果 |
| `pytest-results.png` | 测试命令和终端完整汇总 | 按 README 安装依赖，运行对应 pytest 命令，截取真实汇总及跳过项 |
| `ai-report.png` | 实际生成的报告及其字段 | 在测试环境上传脱敏 CSV，等待任务完成后截取返回的报告 |
| `rag-evaluation.png` | 同一测试集的召回与重排对照 | 在已导入知识数据的环境调用 `src/rag/evaluation.py` 的两个评估函数，保存真实输入、参数和输出后截图 |

RAG 对照应使用相同资料、问题集、模型与召回参数，标注不同的结果数量、指标口径与运行日期。`mean_recall` 在代码中是问题级主题命中率；不要把它解释为标准文档级 Recall。项目提供 `data/rag_test_cases.json`，是否足以支撑结论需另行评估。导入 `examples.import_documents` 会写入数据库，重复导入会产生重复资料，建议在隔离的测试库操作。

完成后把真实图片放入本目录，并在 README 的运行效果章节插入对应相对路径，例如 `![Swagger 接口文档](assets/swagger.png)`。PNG 架构图如果需要，可使用 Mermaid 渲染工具导出 README 中的现有图；当前版本以 Mermaid 为正式图源。
